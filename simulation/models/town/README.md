# vo_town — photorealistic small-town world for UAV visual odometry

A 200 × 200 m static town environment for Gazebo Sim (gz-sim / Ignition, tested on
Gazebo Harmonic 8.11, `<sdf version="1.9">`), built for testing visual odometry from
downward/oblique UAV cameras at 10–60 m altitude.

The world contains **no robot, vehicle, sensor, or camera** — spawn your own drone
into it.

## Launch

```bash
cd <path>/simulation_tools
export GZ_SIM_RESOURCE_PATH=$PWD/models:$GZ_SIM_RESOURCE_PATH
gz sim worlds/vo_town.sdf
```

All assets are referenced as `model://vo_town/...` with textures resolved relative to
each model, so the folder is self-contained — no Fuel downloads or network access
needed at runtime.

## Contents

* **Road network** — 3 × 3 grid of two-lane roads (at x, y ∈ {−52, 0, +52} m) with
  dashed center lines, edge lines, 9 zebra-crosswalk intersections, raised
  paved sidewalks/curbs, and 2 marked parking lots.
* **Buildings (10 reusable models, ~38 instances)** — brick/plaster houses with baked
  window facades and tiled roofs, a shop row with striped awnings and storefronts, a
  glass office mid-rise, a dark lit-window mid-rise, an 18 × 18 × 30 m curtain-wall
  tower with rooftop helipad, corrugated-steel warehouses, and a civic hall. Every
  building type has a unique facade and a detailed roof texture (AC units, vents,
  parapets) so rooftops are feature-rich from nadir views.
* **Props** — trees, streetlights, parked cars (3 colors), street signs.
* **Ground** — four distinct 100 × 100 m grass quadrants (~3 cm/px) with baked mowing
  stripes, dirt patches, worn footpaths, and per-pixel speckle so features are
  locally unique everywhere; a single flat collision plane underneath.

## Design notes (VO + performance)

* All geometry is primitives (boxes, planes, cylinders, spheres) — detail comes from
  baked photo textures + normal maps (PBR `<pbr><metal>`), keeping poly count tiny.
  Measured RTF ≈ 1.0 (cap) with a 1 ms physics step on an RTX 2050.
* Everything is `<static>true</static>`. Collisions: one ground plane + one box per
  building. Roads, sidewalks, and props have no collision.
* Lighting: single directional sun, shadows disabled, moderate ambient.
* Texture filenames are globally unique (`<model>_<map>.jpg`) — ogre2 caches textures
  by URI, so duplicate basenames across models would alias to one texture.
* Facade/road textures avoid large uniform or perfectly repetitive areas: window
  glass tints, stains, cracks, and awning colors are randomized per bake.

## Regenerating / tweaking

The world and all textures are generated by two scripts in `tools/`:

```bash
python3 tools/bake_textures.py     # composites CC0 photos into baked maps (needs ./ext with ambientCG zips extracted)
python3 tools/gen_models_world.py  # writes model SDFs + worlds/vo_town.sdf
```

Edit the layout tables in `gen_models_world.py` (buildings `B`, trees `T`, cars `C`)
to rearrange the town.
